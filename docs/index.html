1. Overview & Commitment to Privacy

Maps Directory Crawler is committed to protecting your privacy. This extension is designed from the ground up to operate entirely on your local machine. We believe that your search queries, prospective leads, and business intelligence belong solely to you.

Key Principle: Zero Remote Data Transmission
Maps Directory Crawler does NOT operate external servers, remote databases, or cloud sync systems. All data extracted and organized using this extension remains stored locally in your browser's private storage.

2. Data Collection and Usage

The extension handles two categories of data:

A. Public Directory Listings

When you explicitly initiate a crawl on an active Google Maps tab, the extension reads publicly accessible information visible on the web page, including:

  • Business name and category
  • Star rating and total review counts
  • Public contact numbers, website URLs, and physical addresses
  • Operating hours and geographical coordinates
  • Public cover photos and Google Maps place links

This information is processed temporarily in-memory and saved directly into your browser's chrome.storage.local database.

B. User Notes, Tags, and CRM Pipeline Status

When you use the built-in Dashboard, any status tags (e.g., Outreach Ready, Contacted, Closed), custom tags, and personal notes you enter are saved strictly on your local browser.

3. Chrome Extension Permissions

To perform its advertised features, the extension requests the following browser permissions:

  • storage and unlimitedStorage: Used exclusively to save and retrieve your scraped directory listings, settings, and CRM notes locally in your browser without hitting storage quota limits.
  • tabs and scripting: Used to communicate with the active Google Maps tab and inject the extraction script when you click the Start button.
  • clipboardWrite: Used solely to allow you to copy business details (phone numbers, addresses, coordinates) to your clipboard with one click.
  • optional_host_permissions (*://*/*): Used strictly on-demand if you enable the optional contact enrichment feature (finding publicly listed business emails and social links directly from the target company's official website).

4. Data Sharing, Sale, and Monetization

We believe in strict data protection principles:

  • We do NOT sell, rent, trade, or lease your data or scraped leads to any third parties or data brokers.
  • We do NOT track your browsing history outside of Google Maps or map search sessions.
  • We do NOT embed third-party tracking scripts, behavioral analytics, or advertising SDKs in this extension.

5. Data Retention, Export, and Deletion

You have complete control over your data at all times:

  • Export: You can export your data at any time into CSV or JSON formats using the Export feature in the Dashboard.
  • Deletion: You can delete individual records or clear the entire local database at any time by clicking the Clear Data button in the extension dashboard.
  • Uninstall: If you uninstall or remove the extension from Chrome, all data stored within chrome.storage.local is permanently purged by Google Chrome.

6. Single Purpose Declaration

In accordance with the Chrome Web Store Developer Program Policies, Maps Directory Crawler has a single, clearly defined purpose:

To enable users to extract, organize, and manage publicly available business directory listings from map search results into a local productivity dashboard.

7. Contact and Inquiries

If you have any questions or feedback regarding this Privacy Policy or the security of the extension, please open an issue on the official GitHub repository:

1. Ringkasan & Komitmen Privasi

Maps Directory Crawler berkomitmen penuh untuk menjaga privasi Anda. Ekstensi ini dirancang secara khusus untuk berjalan 100% di perangkat lokal Anda. Data pencarian, prospek bisnis, dan catatan Anda adalah milik Anda sepenuhnya.

Prinsip Utama: Tanpa Pengiriman Data ke Server Luar
Maps Directory Crawler TIDAK memiliki atau mengoperasikan server eksternal, database cloud, maupun sistem pelacak pihak ketiga. Seluruh data yang diambil dan dikelola disimpan murni di memori lokal browser Anda (chrome.storage.local).

2. Pengumpulan dan Penggunaan Data

Ekstensi ini memproses dua kategori data:

A. Informasi Direktori Publik

Saat Anda memulai proses crawl pada tab Google Maps yang sedang aktif, ekstensi membaca informasi publik yang ditampilkan di halaman peta:

  • Nama tempat dan kategori usaha
  • Rating bintang dan jumlah ulasan publik
  • Nomor telepon publik, alamat website, dan alamat fisik
  • Jam operasional dan koordinat peta (latitude/longitude)
  • Foto profil publik dan tautan Google Maps

Data ini diproses sementara di browser dan disimpan langsung ke database lokal browser Anda.

B. Catatan Pengguna, Tag, dan Status Pipeline CRM

Catatan, label kustom, dan status penawaran yang Anda ubah di Dashboard tersimpan secara privat di browser komputer Anda sendiri.

3. Penggunaan Izin (Permissions) Browser

Ekstensi ini memerlukan izin berikut agar fungsinya dapat berjalan:

  • storage & unlimitedStorage: Digunakan untuk menyimpan dan membuka kembali data hasil crawl, pengaturan, dan catatan prospek di browser tanpa terbentur batas kuota.
  • tabs & scripting: Digunakan untuk berinteraksi dengan tab Google Maps yang dibuka pengguna dan menjalankan script ekstraksi saat tombol Mulai ditekan.
  • clipboardWrite: Digunakan untuk menyalin data prospek (telepon, alamat, koordinat) ke clipboard perangkat dengan satu klik.
  • optional_host_permissions (*://*/*): Digunakan secara opsional hanya saat Anda mengaktifkan fitur pencarian email bisnis publik di website resmi tempat yang ditemukan.

4. Berbagi Data, Penjualan, dan Monetisasi

Kami menjunjung tinggi etika perlindungan privasi:

  • Kami TIDAK menjual, menyewakan, atau memperdagangkan data atau prospek Anda kepada pihak ketiga atau pialang data (data broker).
  • Kami TIDAK melacak riwayat penelusuran web Anda di luar sesi pencarian direktori Google Maps.
  • Kami TIDAK menyisipkan script analitik pelacak perilaku atau jaringan iklan pihak ketiga di dalam ekstensi ini.

5. Penyimpanan, Ekspor, dan Penghapusan Data

Anda memegang kendali penuh atas data Anda:

  • Ekspor: Anda dapat mengekspor data kapan saja ke format CSV atau JSON dari halaman Dashboard.
  • Hapus: Anda dapat menghapus data tertentu atau mengosongkan seluruh database lokal melalui tombol Hapus Semua Data di Dashboard.
  • Uninstall: Jika Anda menghapus ekstensi dari Chrome, seluruh data di chrome.storage.local akan otomatis dihapus permanen oleh browser Google Chrome.

6. Deklarasi Tujuan Tunggal (Single Purpose)

Sesuai dengan Kebijakan Program Pengembang Chrome Web Store, Maps Directory Crawler memiliki tujuan tunggal yang jelas:

Memungkinkan pengguna mengekstrak, mengorganisir, dan mengelola daftar direktori bisnis publik dari hasil pencarian peta ke dalam dashboard produktivitas lokal.
